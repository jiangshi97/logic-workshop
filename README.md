# 逻辑工坊：从逻辑门到汇编程序

从信号连线开始，逐步搭建逻辑门、加减法器、寄存器与存储器，最后连接成能执行指令的八位计算机，并用汇编完成算法任务。

## 运行

需要 Node.js 20.19+ 或 22.12+。在本目录运行：

```powershell
npm.cmd install
npm.cmd run dev -- --port 5173
```

打开 http://127.0.0.1:5173/ 。首次进入第一关，通过后依次解锁后续关卡。

也可运行 `npm.cmd run start:local` 启动隐藏的后台开发服务；PID 保存在 `server.pid`，日志在 `server.log` 和 `server-error.log`。需要其他端口时运行 `npm.cmd run start:local -- 5174`。停止自己启动的服务可根据 `server.pid` 用 `Stop-Process -Id <PID>`。

局域网访问可运行 `npm.cmd run dev -- --host 0.0.0.0 --port 5173`，其他设备使用本机局域网 IP 与端口访问。随机 ID 生成兼容局域网 HTTP 环境。公网部署可将 `dist/` 放到静态 HTTPS 服务。

使用时可以从输出端口拖到输入端口，也可以依次点击两个端口。点击输入节点切换 0/1，点击测试运行本关公开测试集；时序关按场景推进时钟。点选逻辑门或导线后可以删除；固定输入输出不可删除。输入已有导线时，先删除旧连接。

拖动空白区域框选，按住空格或中键拖动平移；支持缩放与适应画布。Ctrl+Z 撤销，Ctrl+Shift+Z / Ctrl+Y 重做，Delete 删除，Ctrl+D 复制所选逻辑门及其内部连接。

## 已实现

- 56 个基础关：第1–20关组合逻辑、第21–32关“状态与时间”、第33–44关“计算机架构”、第45–56关“编程应用”，全部为 content/levels/ 下的声明式 JSON 数据；此后新增关卡走 content/packs/ 关卡包（example 包带一个示例扩展关）。
- 鼠标拖动与点击连线、逻辑门拖放、节点移动、框选、复制、删除、撤销重做。
- 1/2/4/8/16位信号；支持部分未知位、多输出接口、总线拆分与合并、可配置常量。
- 独立数学参考函数和时序状态机判题；失败自动完整回放，输出和相关导线高亮；抽样关明确标示测试集。
- 三层提示、关卡解锁、每关独立草稿和独立通关证明。
- 自动存档、JSON 导入导出；导入重新验证证明；存储失败持续提示。
- 桌面工作台、平板与手机抽屉布局。
- 通过后保存整个电路为组件；所选电路可封装成组件实例；组件可嵌套、复用、查看内部电路或展开。
- 同名组件保存为新版本，旧实例继续引用原版本。所有输入、输出和内部连接随组件保存。
- 实时仿真、穷举判题、存档解析与证明验证在 Web Worker 中执行；大型真值表分页展示，后台任务可以取消。
- DFF 存储原语、统一时钟、同步复位、使能寄存器、计数器、移位寄存器、两级流水及用寄存器搭建的两格/四格存储器。
- 单步周期、连续运行/暂停、清零试验状态、最多 64 次观察的波形，以及从初始状态完整回放失败序列。
- 八位ALU、双寄存器组、PC、16位指令字段、三阶段控制、256×16 ROM和256×8 RAM、输出端口与完整CPU。
- 23个可查看、展开的教学模块，按已完成关卡提供；添加时保存完整依赖。ROM十六进制编辑可撤销，机器观察显示真实PC/IR/Phase/A/B/Z/Memory/Out/Halt/Fault。

## 仿真与当前范围

交互和反例回放使用DigitalJS 0.14.2的HeadlessCircuit/SynchEngine；批量判题编译实际门级网表并执行。两个路径通过所有已交付时序场景、完整运行状态和未知信号等价测试。显示与编辑使用React Flow。没有用指令解释器替代玩家CPU。

当前支持组合逻辑与统一时钟的同步时序逻辑。DFF 在时钟上升沿采样，rst 优先清零；全部存储元件先采样旧值再同时更新，输入改变不自动推进时钟。初始状态为 0，不模拟真实电气传播延迟。展开后的组合反馈、多驱动、位宽不一致、缺失或递归组件依赖在仿真前拒绝；经过 DFF 的状态反馈可以使用。每个可见电路最多 200 个节点、400 条连接；嵌套展开最多 2,000 个节点、5,000 条连接，深度最多 16 层。组件库最多保存 256 个版本，存档最多 4 MB。

后台判题编译一次门级图，按拓扑计算实际门、总线及三值信号；时序场景先求旧值、同时提交状态、再求新值，每个场景从零开始，程序场景使用独立ROM。实时仿真和判题使用不同线程，编辑或切关会取消过期判题。交互仍依赖锁定SynchEngine的同步信号提交行为，升级库应重跑等价测试。完整44证明后台重验实测约1.23秒（本机），不承诺所有设备同速。

历史通关证明独立于草稿，修改或重置不会抹掉学习进度，但旧结果不能证明新草稿。存档为 v7 稀疏格式：只保存动过的关卡，规范组件定义不写入文件、载入时由代码重建，因此文件更小且不受后续指令集/架构演进影响；旧存档中代码已不认识的规范键（如更名前的组件）会作为玩家组件保留；关卡包的一次性事件（如首次通关的彩蛋消息）以 firedHooks 记录、不会重放，钩子写入的本关私有数据存于 packState 字段。兼容导入 v1 四关、v2 二十关、v3 三十二关、v4 四十四关及 v5/v6 全量档，缺失或未知关卡键只忽略不拒档；导入在后台检查结构并逐关重验连续证明，成功后一次性替换工作区。非ROM节点携带words会拒绝导入。

寄存器与RAM实例按路径隔离。切关、结构/ROM变化、导入或刷新重新从零试验，移动节点保留状态。寄存器、RAM运行数据、周期数和波形不写入存档。ROM程序保留。

撤销恢复节点、位置、参数和全部连接，封装、展开、复制、删除与重置均可撤销。不可变组件版本保留在库中，以保护草稿及通关证明的引用。撤销历史、当前选择与临时判题结果不跨刷新保存。

手机可通过抽屉查看任务与添加组件，画布自动缩放；完整编辑体验优先针对桌面。导入会替换此应用的整个存档，仅在格式与全部电路合法后执行。

浏览器验收包含 512 组输入的后台判题，并在判题期间切换输入及检查动画帧持续推进。第三方仿真库仍带来较大的构建包；生产部署建议启用压缩和静态资源缓存。

```powershell
npm.cmd run build
npm.cmd run test:e2e
```

浏览器测试使用 Playwright。当前机器已有 Chromium 时使用本机安装；其他机器可先运行 `npx.cmd playwright install chromium`。

测试用参考电路位于 `tests/fixtures.ts` 和 `tests/sequential-fixtures.ts`。原 20 关覆盖 1,672 组输入，其中第 12、18 关各 512 组。12 个时序关卡覆盖 190 个独立场景、6,899 个观察步骤，包括全部 256 个八位数据、保持与复位优先、回绕与单元隔离，以及同沿写入/读取旧值。时序判题为每个场景清零状态，并复用一次编译的门级网表。参考期望通过独立数学状态机产生。

原 20 关验收记录见 [验收记录](docs/acceptance-report.md)，时序阶段方案见 [状态与时间](docs/state-and-time-design.md)，新阶段通过 96 项单元测试、25 项生产版浏览器测试和生产构建，详见 [时序阶段验收记录](docs/state-and-time-acceptance.md)。

## 状态与时间试玩

原 20 关完成后会解锁第 21 关。试玩可使用 [阶段示例存档](docs/state-and-time-demo.json)：先导出自己的存档备份，再通过“导入存档”加载。示例保留原 20 关的合法通关证明，第 21–32 关有已连好的参考电路；从第 21 关开始观察、单步、测试，再逐关进入后续任务。示例不是当前个人存档的合并操作。

“清零状态”保留电路，只将寄存器和周期重新置零。“重置当前电路”移除元件和连接，可撤销。R 为电路自身同步复位，需要单步周期才生效。测试表的每一行可以从场景初始状态回放到该步，“波形记录”显示当前试验的最近观察。

## 计算机架构试玩

原32关完成后解锁第33关。先导出自己的存档备份，再导入[架构阶段示例](docs/computer-architecture-demo.json)，可直接从第33关开始；所有新关已准备好参考电路，原32关有合法证明。

第44关默认演示程序：MOVI A,7 → MOVI B,5 → ADD → STORE240 → MOVI A,0 → LOAD240 → OUT → HLT。开启E后单步或运行，正常最终Out=12、Halt=1。每条普通指令经历取指、译码、执行三个有效周期；输出只在OUT执行时更新。R需要时钟沿才清状态和RAM，ROM不变。暂停/E=0冻结状态，HLT或非法编码后要复位重启。

“编辑ROM程序”支持0000–FFFF十六进制字、最多256字，未填写地址为NOP。机器观察和程序表标出实际PC、IR与阶段。测试失败会重放相应测试程序和完整历史，继续单步保持该测试程序；“清零状态”回到自己保存的ROM。

新阶段包含89696组组合输入、29个时序场景/8238观察步；其中CPU为10个程序/525步。第37关检查全部65536编码；其他组合关使用公开确定测试集，CPU使用有限程序集合，通关表示通过公开测试。阶段方案见[架构设计](docs/computer-architecture-design.md)，验收记录见[架构验收](docs/computer-architecture-acceptance.md)。该阶段已验收；后续编程应用见下文。

## 编程应用试玩

完成第44关后解锁第45关。本阶段12关包括汇编输出、字节溢出、内存搬运、倒计时、条件分支、加法、常数乘法、累加求和、奇偶判断、四格求和、斐波那契和两数相乘。

先导出个人存档备份，再导入[编程阶段示例](docs/programming-applications-demo.json)，从第45关开始。示例保留原44关合法证明，所有新关有已应用的参考汇编和固定CPU；输入用例载入RAM，点“测试程序”验证算法，再进入下一关。也可在[参考程序](docs/programming-reference-programs.md)中查看12个合法程序，尝试自己的算法。

汇编支持当前ISA的10条指令、前向标签、分号注释及十进制/0x十六进制字节；最多256条指令、32,000字符。语法错误显示源行号并阻止应用，源与ROM作为一次可撤销操作保存。未应用的编辑不会执行或保存；应用相同源也会重新载入用例。

指令单步最多推进三个有效周期；周期单步用于观察取指与执行。快速运行分批在Worker中执行真实门级图，每批至多90周期，到HLT、FAULT、断点或用例预算时停止。地址断点在取指前命中，继续时跳过当前地址一次，下次循环仍会停下。E/R可直接操作：E=0保持机器，R在时钟沿清RAM；“重启用例”重新载入题目输入。

观察器显示真实寄存器、PC与源行、RAM分页及每次OUT事件。即使连续输出相同数，也分别记录。379组公开用例检查完整输出序列、正常停止和任务需要的内存；超预算诊断未停止。通关证明指通过公开测试集，不代表穷举全部程序或算法。失败回放使用玩家保存的ROM及对应RAM输入，重建到实际失败周期，可以继续单步；最近64周期保留在运行数据中。

CPU与组件依赖固定，允许移动布局、观察内部电路和编写程序；不能修改硬件以绕过任务。原1–44关仍用于搭建电路。旧存档迁移补入完整机器依赖，遇到同一固定组件版本内容被篡改时拒绝导入。RAM运行值、输出记录、断点、用例选择和撤销栈不跨刷新保存。

最终验收：254项单元测试、36项生产版浏览器检查和生产构建通过。

设计见[编程应用方案](docs/programming-applications-design.md)，验收见[编程应用验收](docs/programming-applications-acceptance.md)。阶段完成后暂停，供用户试玩。
